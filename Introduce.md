In the digital world, adders are fundamental components of almost all numerical processing systems, from simple microprocessors to complex supercomputers.
By combining the functionality of an adder with the ability to perform subtraction via two's complement, this Adder/Subtractor circuit effectively demonstrates the integration of basic arithmetic operations within a single integrated circuit design.

*** Features
Dual Operation: Performs both addition and subtraction for N-bit binary numbers.

Two's Complement Arithmetic: Subtraction is efficiently handled using the two's complement method, a standard technique in digital systems.

Modular Design: The circuit is designed with modularity in mind, allowing for easy expansion to different N values (e.g., 4-bit, 8-bit, 16-bit, etc.).

Understandable Code: The code is written clearly and well-commented, making it easy to grasp the logic and structure of the circuit.

*** Project Goals
The main goals for this project were to:

Reinforce knowledge of combinational logic and sequential logic (if registers or states are involved).

Practice designing and implementing basic arithmetic circuits.

Illustrate the use of two's complement in subtraction operations.

Create a useful project that can serve as a reference or a starting point for more complex designs in the future.
